What the rules catch

The double-submission guard

Agencies retitle the same req constantly. The guard matches on req id, URL, employer — and the job description body itself, reordered templates included. Warnings are surfaced for you to weigh, never silently resolved.

Never an invented fact

An application date that was never recorded stays "unknown" — the agent is refused if it tries to guess. When the true date surfaces, a correction records it with its source.

Ghosted is a status, not a deletion

Silence is an outcome, and which companies go quiet is pattern knowledge. Terminal states stay on the books, one click away.

One open next action

Per pursuit, one thing to do next, with a due date. The Due page is your morning list; superseded intentions are kept, not erased.

How it works with Claude

1. Sign in above — you get a private, persistent space.
2. In the sidebar: Share this space… → Mint key → copy the agent link (https://saybooks.io/mcp/m-…).
3. In the Claude app: Settings → Connectors → Add custom connector — Name: hunt, Remote MCP server URL: your agent link.
4. Open a new session with the connector on, and paste this with a job description under it:

You're my job-hunt assistant, connected to my Saybooks hunt space through the "hunt" connector. Call core_schema first to learn the rules. Then log the posting below: evaluate the fit, run the duplicate check, and give me one next action with a due date.

From then on, just talk: "the recruiter called, interview Thursday" · "TCS ghosted me" · "what's due today?" Everything it records shows up here in the browser too — same data, same rules, one audit trail. Works with any MCP-capable agent (Claude Code: claude mcp add hunt -t http <agent link>).

Your data, actually yours
  • Export — one click downloads every table as JSON, audit log included.
  • Delete — one button permanently removes your space, its database, and every access key.
  • Self-host — the whole thing is open source (AGPL): github.com/alviso/saybooks. Run it on your laptop if you'd rather.
  • No LinkedIn integration, by design — nothing here touches your account or scrapes anything. You and your agent record what you know.
